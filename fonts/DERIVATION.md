# Bundled font derivation

Noto Sans KR and Noto Sans SC were downloaded from the official google/fonts repository under SIL OFL 1.1. Their weight axis defaults to 100. For readable subtitles, fontTools 4.67.0 varLib.instancer instantiated wght=400. Derived family names are MMLearningSourceKR and MMLearningSourceSC; original copyright and OFL records are retained. NotoSans.ttf is the original variable Noto Sans file, whose default weight is 400. The Java helper subsets these files locally into a font named MMLearningFont.

Original sources: https://github.com/google/fonts/tree/main/ofl/notosanskr and https://github.com/google/fonts/tree/main/ofl/notosanssc . Full original licenses are beside the fonts. No game fonts are included.
