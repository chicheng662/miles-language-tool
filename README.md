# Miles Language Tool · 蜘蛛侠多语言字幕工具

把《漫威蜘蛛侠：迈尔斯·莫拉莱斯》和《漫威蜘蛛侠 2》中的对话变成语言学习素材：双语紧邻或上下分屏，两层语言与样式独立配置。

**v0.3.0 预览版 · Windows 64 位 · 源码公开，非商业许可**

## v0.3.0：接入《蜘蛛侠 2》

同一个工具自动识别两款游戏，分别检查资源版本、生成字幕、备份和还原。二代沿用游戏原生 HTML/JS 字幕界面和英语时间轴，支持相同的双层配置。22 种字幕语言已完成文本配对审计；各游戏的字形和实机验证状态独立记录，详见 [验证报告](验证报告.md)。

| 游戏 | 支持的资源版本 | 选择的目录 |
| --- | --- | --- |
| 迈尔斯·莫拉莱斯 | 4.0630.0.0 | 包含 `MilesMorales.exe`、`asset_archive/toc` |
| 蜘蛛侠 2 | 2.810.0.0 | 包含 `Spider-Man2.exe`、根目录 `toc`、`d/` |

兼容性同时检查资源哈希。未知版本和其他索引修改会停止覆盖。两款游戏分别保留原始备份，不互用生成的资源包。

## v0.2.0：大英文在上，小中文在下

在工具中点击 **“英文优先：大英文在上 · 小中文在下”**，然后生成并应用。两行会在屏幕下方紧邻排列，英文默认 36、中文 24；字号可分别调整，并可设置距底部和两行间距（预设为距底部 100、行间距 8 输出像素）。长句按实际文字高度排列；单层关闭时不保留空行。

原来的 **上下分屏** 仍可选择。v1 JSON 配置导入后保持原来的分屏布局，导出为 v2。切换布局不等于立即改动游戏，需要关闭游戏并应用。

## 功能

- 选择游戏现有的 22 种字幕语言，交换上下语言，或关闭其中一层。
- 独立设置字号、描边、背景；设置顶部间距和游戏输出分辨率。
- 本地生成原生字幕补丁、校验资源、保留原始索引备份；支持重新配置和还原。
- 导入/导出版本化 JSON 配置；生成本地缺译覆盖报告。
- 新配置默认：底部双语紧邻，大英文在上、小中文在下。也可切换为上下分屏，顶部默认间距约 20 输出像素。菜单保持简体中文。

## 下载与使用

从本仓库 **Releases** 下载 Windows 便携 ZIP，完整解压，双击 `MilesLanguageTool.exe`。无需安装 Python 或 Java。选择游戏目录、核对分辨率，关闭游戏后生成并应用字幕。

在游戏中开启字幕，使用 **简体中文文本 + 英语配音**。修改游戏分辨率后重新应用。详细流程见 [工具使用说明](工具使用说明.md)。

迈尔斯启动器可能把 4.0630.0.0 显示为 4.630.0.0。是否兼容以资源哈希为准。

工具从玩家自己的游戏中读取资源。仓库和发行包不包含完整游戏台词、原始界面资源、生成后的游戏补丁或存档。

## 验证状态

二代已在 2560×1600 的实际开场过场显示英文上行、简中下行，确认中文名字、换句与隐藏。22 种语言完成 29,609 条英语时间轴的文本配对审计；二代其他语言的字形尚待实机抽查。

迈尔斯原有验证：57 项检查在受支持游戏环境通过；2026-10-31 用户在 2560×1600 的真实对话场景确认“大英文在上、小中文在下”已恢复。旧分屏模式的中英真实过场、长句换行、单层、互换和多语言字形样例已抽查。字体样例通过不能替代全剧情同步验收。

完整剧情、所有暂停/跳过/读档组合、16:9 与超宽屏实机、从未安装 Python/Java 的干净 Windows 实机仍待验收，详见 [验证报告](验证报告.md)。预览是示意，游戏内效果为准。

## 开发与测试

Python 3.14 在 Windows 上已验证。基础测试无需游戏或第三方 Python 包：

```powershell
python -m unittest discover -s tests -v
```

没有游戏资源时，本地集成测试会明确跳过；格式、配置、安装事务、DOM 生命周期与 GUI 检查仍运行。GUI 检查使用 Tkinter，DOM 检查需要 Node.js，CI 在 Windows 上运行。若希望运行完整本地集成测试：

```powershell
$env:MILES_GAME_DIR = 'C:\Games\MilesMorales'
$env:MILES_OVERLAY_AS = 'C:\LocalExports\OverlayManager.as'
$env:MILES_MSM2_GAME_DIR = 'C:\Games\SpiderMan2'
python -m unittest discover -s tests -v
```

`MILES_OVERLAY_AS` 是从玩家自己的原始 Overlay.gfx 导出的脚本，不随项目分发。开发启动、运行时准备与打包步骤见 [BUILDING.md](BUILDING.md)。
